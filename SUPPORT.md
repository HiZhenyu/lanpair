# Getting help

1. **Read the docs.** The [README](README.md) shows how to use lanpair, and
   [docs/design.md](docs/design.md) explains how it works and what it protects against.
2. **Search the [issues](https://github.com/TonyD365/lanpair/issues?q=is%3Aissue)**: someone may
   have had the same problem.
3. **Ask in [Discussions](https://github.com/TonyD365/lanpair/discussions)** for questions and
   ideas.
4. **Open an issue** with the [form](https://github.com/TonyD365/lanpair/issues/new/choose) for a
   bug. English or Chinese are both fine.

Security problems are different: see [SECURITY.md](SECURITY.md).
